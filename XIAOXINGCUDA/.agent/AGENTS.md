# git规范
- 什么时候使用git
> git是一个代码管理工具 前端部分必须使用git，典型情况是React与Electron，如果是单纯的html+css+js不需要使用，其判断标准可以判断是否有npm init 后的文件 对于C# python c c++ 没有看到git的文件 禁止使用
- git 规则
  1. 仅当用户明确要求进行 Git 推送（如“推送到远程”、“git push”、“提交并推送”等）时，才可执行推送操作
  2. 禁止在未经用户明确授权的情况下主动推送
  3. 禁止单文件推送，所有推送需确保关联变更完整
  4. 可使用 git diff 或 git status 向用户展示当前代码变更摘要，以便用户审查
  5. 在提交前，应主动向用户展示待提交变更的主要内容
  6. 一般情况只有一个分支
  7. 在使用git命令时候应该明确表示使用命令的目的
  8. 在执行危险操作时候 必须让我授权处理，下面的命令是典型的危险操作`it push --force、git push -f  git reset --hard`
  9. 推送时候必须是utf-8 的中文说明， 必须是说明这次推送的目的
